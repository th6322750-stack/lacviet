# Design placeholders

The following values may be invented for mockup/composition purposes only and MUST NOT be treated as factual business claims in production code or public launch content.

## Allowed placeholder categories
- customer counts
- years of experience
- success/appeal rates
- response/support times
- campaign/account volumes
- case-study metrics
- ROAS/revenue/conversion figures
- testimonial names/roles/quotes

## Hard rule
Every placeholder value must be replaced with verified real data before production launch. Until then, implementation should mark such content as `PLACEHOLDER` in source/data files or omit it from public deployment.
